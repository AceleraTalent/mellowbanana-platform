# Guía de uso del equipo (plataforma + Claude)

Fuente: `guia-src.html`. Está publicada como artefacto de claude.ai en
https://claude.ai/artifact/GbSzyu2VggSB6BR7JKiK1c (privado; se comparte desde el menú Share).

Para editarla: cambiar `guia-src.html`, correr `node scripts/build-guia.mjs` y publicar
`out/artifact.html` encima del mismo artefacto. `out/` queda fuera del repo porque lleva
ABC Favorit incrustada (licencia del estudio); el fuente solo tiene los marcadores.

El fuente también se puede pedir a Claude Code en cualquier sesión: "actualiza la guía
del equipo" con esta ruta y la URL del artefacto alcanza.
